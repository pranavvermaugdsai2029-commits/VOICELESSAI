# VOICELESS AI

VOICELESS AI is a comprehensive suite for sign language recognition and communication, consisting of three main components:

1. **SIGNDEVSIGN**: A frontend streaming application for sign language interaction.
2. **SignDETR**: A backend detection system based on the DETR architecture+CNN(Resnet Backbone).
3. **my-rasa-assistant**: A Rasa-powered chatbot assistant for sign language integration.

## Dataset Information
> [!IMPORTANT]
> These components were created with a dataset of 3000+ custom images.

## Structure
- `SIGNDEVSIGN/`: Frontend streaming app.
- `SignDETR/`: Backend sign language detection.
- `my-rasa-assistant/`: Custom Rasa assistant.
